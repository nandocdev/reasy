# Reasy — Historical Prototype

> ⚠️ **Historical project:** Reasy is no longer the current product direction of NandocDev.

Reasy was an earlier exploration of a multi-tenant booking SaaS using Laravel, Livewire, PostgreSQL and modular architecture.

The repository is kept public as a record of the architecture and product exploration that preceded the current SaaS work.

## Status

- **Development:** discontinued
- **Purpose:** historical reference
- **Current product direction:** Vantio
- **Code:** preserved as-is for reference

## Historical architecture

- Laravel
- Livewire
- PostgreSQL
- PostgreSQL Row-Level Security
- Redis
- Modular monolith
- Multi-tenancy

> This repository should not be considered production-ready or representative of the current NandocDev implementation.
